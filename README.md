# CAMELS-2-HBV-Light
Input projects for [HBV-Light](https://www.geo.uzh.ch/en/units/h2k/Services/HBV-Model.html) ([Seibert and Vis 2012](https://hess.copernicus.org/articles/16/3315/2012/hess-16-3315-2012.html)) for the 671 GB catchments in the CAMELS-GB2 dataset ([Coxon et al 2025](https://doi.org/10.5285/9a46d428-958f-4ac1-86eb-94eee70c0955)), covering the full 1970-10-01 to 2022-09-30 daily record. For each catchment, the dataset has been split into calibration and validation time periods on a 50:50 basis.  
In the *src* folder, there is the python script that was used for the processing. CAMELS-GB2 provides two products for precipitation/PET/temperature: a CEH-GEAR/CHESS-PE combination (matching the original CAMELS-GB v1 methodology, but only available to 2019-12-30) and a HadUK-Grid precipitation/temperature + "hydrope" PET combination that spans the full record. The processing script uses the latter so the resulting series covers the full 1970-2022 period.  

Reaney S. M. 2022: CAMELS-2-HBV-Light: A set of 671 catchments for HBV-Light based on the CAMELS-GB2 dataset. https://github.com/simreaney/CAMELS-GB-2-HBV-Light
